# fs-jscalendar

The shared types of the JSCalendar 2.0 standard for FreeSynergy: time and zones, recurrence rule, participants, upgrade from RFC 8984, shared validation, iCalendar conversion.

A plain library: no data, no storage, no interface, no program (ADR 0050). `Event` belongs to [fs-calendar](https://github.com/FreeSynergy/fs-calendar), `Task` to [fs-tasks](https://github.com/FreeSynergy/fs-tasks). Licence: MIT OR Apache-2.0.
